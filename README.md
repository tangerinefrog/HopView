# HopView

Real-time traceroute visualization on an interactive map.

<img width="400" height="500" alt="image" src="https://github.com/user-attachments/assets/cf158f5e-230e-4d16-b7b9-47c8485516d6" />


## What it does

- Runs traceroute to any endpoint (domain or IP)
- Geolocates each hop using IP geolocation
- Plots the route on an interactive map using MapLibre
- Updates in real-time as traceroute progresses
